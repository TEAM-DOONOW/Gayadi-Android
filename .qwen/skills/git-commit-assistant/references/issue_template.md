# Issue Template

## Title

`[<type>] <간결한 이슈 제목>`

## Body

```markdown
### 🔥PURPOSE

> <!-- 해당 이슈의 목적을 작성해주세요 ex) Todo 생성 기능 -->

### 📒TODO

- [ ] <구체적인 작업 항목 1>
- [ ] <구체적인 작업 항목 2>
- [ ] <구체적인 작업 항목 3>
```

## Rules

- PURPOSE는 한 문장으로 핵심 목적을 서술.
- TODO는 체크리스트 형태로 구체적 작업 단위를 나열.
- 한국어로 작성.
- 이슈 번호는 브랜치명 `<type>/#<issue-number>-<description>`에서 추출.
