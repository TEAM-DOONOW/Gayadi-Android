# PR Template

## Title

`<type>/#<issue-number>: <subject>`

## Branch

`<type>/#<issue-number>`

Do not append a description after the issue number.

## Body

```markdown
## 📌 Summary

<!-- PR 요약을 써주세요. -->

## ✍️ Description

<!-- PR에 대한 자세한 설명을 써주세요. -->

- close: #<issue-number>

## 💡 PR Point

<!-- 코드를 작성할 때 고민했던 부분을 적어주세요 -->

## 📚 Reference

<!-- 참고할 만한 자료가 있다면 링크나 시각 자료를 달아주세요. -->

## 🔥 Test

<!-- Test -->
```

## Rules

- Summary: 한두 문장으로 변경 핵심 요약.
- Description: 변경 사항 상세 설명. `close: #<issue-number>`로 이슈 연결.
- PR Point: 설계 판단, 트레이드오프, 리뷰어가 주목할 부분.
- Reference: 관련 문서, 디자인 시안, API 스펙 링크.
- Test: 검증 방법 (수동 테스트 절차, 스크린샷 등).
- 한국어로 작성.
